# Sustainable Tourism Readiness in Malaysia

This project uses Malaysian state-level socioeconomic, environmental, and tourism data to explore sustainable tourism readiness. The analysis is in [`DATAVERSE_Datathon2026_Colab.ipynb`](DATAVERSE_Datathon2026_Colab.ipynb), a Google Colab/Jupyter notebook.

The notebook downloads public datasets, combines and engineers state-level indicators, calculates economic, social, environmental, and tourism scores, then uses K-Means clustering and a Random Forest classifier to explore readiness patterns. It also prepares tourism demand and pressure summaries for further analysis in Power BI.

## Run the notebook

1. Open `DATAVERSE_Datathon2026_Colab.ipynb` in [Google Colab](https://colab.research.google.com/) or a Jupyter environment.
2. Run the first cell to install the Python packages listed in [`requirements.txt`](requirements.txt).
3. Download the [international hotel guest dataset](https://archive.data.gov.my/data/dataset/malaysia-hotel-guest-international-by-state) and the [average hotel occupancy-rate CSV](https://archive.data.gov.my/data/dataset/malaysia-average-occupancy-rate-of-hotels/resource/b15a3720-9c70-4aa7-8c65-912ee9077d42). Upload them to the notebook runtime, naming them to match the expected paths:
   - `/content/data/raw/2015 2022 MALAYSIA INTERNATIONAL HOTEL GUESTS  .csv`
   - `/content/data/raw/_202306010434400_2015-2022-malaysia-average-occupancy-rates-by-state.csv`
4. Run the notebook cells in order. Public datasets are downloaded when the notebook runs, so results may change as source data is updated.

The notebook creates `data/raw/`, `data/processed/`, `outputs/`, and `models/` as needed. The tourism input files are not included in this repository; add them to the Colab runtime (or update the notebook paths) before running cells that use them.

## Data sources

The notebook retrieves public datasets from:

- [Department of Statistics Malaysia (DOSM) OpenDOSM](https://open.dosm.gov.my/) — state GDP, household income and expenditure, labour, population, and CPI.
- [data.gov.my](https://data.gov.my/) — forest reserves, water access and consumption, and arrivals by state of entry.
- [data.gov.my archive: International hotel guests by state](https://archive.data.gov.my/data/dataset/malaysia-hotel-guest-international-by-state) — tourism input used by the notebook.
- [data.gov.my archive: Domestic hotel guests by state](https://archive.data.gov.my/data/dataset/malaysia-hotel-guest-domestic-by-state) — related dataset available for future use; the current notebook does not load domestic hotel guest data.
- [data.gov.my archive: Average hotel occupancy rate by state (2015–2022)](https://archive.data.gov.my/data/dataset/malaysia-average-occupancy-rate-of-hotels/resource/b15a3720-9c70-4aa7-8c65-912ee9077d42) — occupancy-rate input used by the notebook.

Hotel guest and average occupancy-rate data are downloaded separately and supplied as local inputs to the notebook. Check the relevant source terms and attribution requirements when reusing data.

These files are generated by running the notebook and are not committed. The analyses are exploratory; review the notebook's assumptions and validate the results before using them to support decisions.
